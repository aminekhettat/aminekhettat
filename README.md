# 🛠️ Hi there, I'm Amine Khettat 👋

**Senior Embedded Systems, Automation & Robotics Engineer** *Building hardware with a unique vision and high-torque passion.*

---

### 👁️‍🗨️ My Engineering Philosophy: Accessibility by Design

I am a **blind engineer**, which gives me a "superpower" in software architecture: I don't just add accessibility as an afterthought; I build it into the core. 

* **The Signature Block:** Every project I develop includes a dedicated architectural layer for UI accessibility.
* **Universal Design:** I believe that if a machine can't talk to everyone, it's not finished yet.

---

### 🚀 What I'm up to

* 🔭 **Currently working on:** Advanced embedded firmware and robotics control systems.
* ⚡ **Fun fact:** I can often "debug" an electric motor's health just by listening to the frequency of its PWM.
* 🎸 **Obsessions:** High-torque electrical motors, automation logic, and high-fidelity music.
* 🌱 **Learning:** Always refining my Python stack (Ruff, Mypy) and exploring new RTOS kernels. Also, i love analyse and reverse  source codes especially those  dedicated for electrical motor control (BLDC, PMSM, ...etc).
